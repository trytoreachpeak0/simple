# 启用的车上看到有人在手动用车，SIMPLE 取消自己的单、停手、算故障，不自动恢复

人要手动用车，规矩是先在控制台停用（ADR 0011）。但现场的人可能不停用就直接动车：用手控器开、松抱闸推、在 Matrix 上让车走、推去插手动充电器。按前几场的规则，SIMPLE 这时会和人抢车：给它建去充电的单、从挂起自动继续、重建被取消的单，抱闸一合上车可能自己又走了。产品负责人说这种行为人难以理解，人也不知道该做什么（2026-10-16）。所以 SIMPLE 一看到有人在手动用车，就取消自己的单、停手，交给人，不再自己恢复；人的出口只有两个：在控制台停用这台车，或者用完后由班组长按"继续"。

## 决定

- **手动用车的四种迹象**（启用的车，出现任何一种就算）：

  | 迹象 | 人做了什么 | 看什么 |
  | --- | --- | --- |
  | 车在手动模式 | 用手控器开车，人可以直接让车前后左右走 | 车队调度系统报 `mode` 为 `MODE_MANUAL`，按原字符串精确比对 |
  | 抱闸松着 | 松抱闸推车 | `breakSwitchState` 为 `UNMOVABLE`（这个字段的命名是反的：抱闸合上时叫 `MOVABLE`） |
  | 车在动，车上却没有任何订单 | 在 Matrix 上让车走 | 速度不为 0，车上没有任何车队调度系统订单 |
  | SIMPLE 没让它充电，它却在充电 | 插了手动充电器 | `batteryState` 为 `CHARGING`，而这台车的用途不是充电 |

  后两种是两个读数凑在一起判断的，要连续两次读数都成立才算，免得订单刚结束、车还在减速，或刚离桩时读到一次就误判；沿用 ADR 0003 判断需求消失时"连续两份快照"的做法，不加计时器。

- **取消自己的单，然后停手**（产品负责人 2026-10-16）：手动用车是一种故障（见下），车一进入故障，服务端就按 ADR 0012 取消这台车上 SIMPLE 所有没结束的移动单，排队、执行、暂停、挂起的都算；不下急停。之后不建新单、不重建、不送去充电。不取消的话，松着抱闸时排着的单会在抱闸一合上时当场执行，人推完车，车就自己开走了。这是 ADR 0021"车进入故障时取消"的一种。这些单是 SIMPLE 自己取消的，不算 ADR 0010 的"被别人取消"，不会自动重建。车上的任务不结束，留在故障处置里。往安全方向走的动作照旧，例如车在行驶中、门锁没证明锁闭时下三类急停（ADR 0008、0009）；ADR 0009 只为门锁这一种原因下急停，这里不为手动用车另下急停。
- **算这台车的车辆本体故障**：这些迹象都是从 AGV 车体上读到的，类别只是标签（ADR 0012）。告警给班组长（ADR 0013、0014），控制台和车载终端上写明是哪种迹象，以及"要手动用车，请先在控制台停用这台车"。车上已经有没结束的故障时不另算：故障处置中车挡了路，人本来就可以松抱闸把车推开（ADR 0012）。
- **不自动恢复**：迹象消失了（切回自动模式、抱闸合上、拔了手动充电器），故障也不自己结束，免得车自己又动起来、人看不懂。出口只有故障处置的两个：人用完了，班组长按"继续"，服务端先核对四种迹象都已消失、门锁条件满足（ADR 0009），再按这一趟剩下的任务重建，让车接着做原来的事；要接着手动用，就停用这台车。按"继续"时核对"四种迹象都已消失"对所有故障都做，不只是手动用车引起的故障：例如故障处置中人松抱闸把车推开（ADR 0012），没合上抱闸就按"继续"，服务端不执行，并提示"抱闸松着"。车上有货的，照 ADR 0012 可以先取出货物。
- **改写 ADR 0010 的一处**：车在跑单时被人松了抱闸，订单挂起，原来是抱闸合上、条件满足就自动继续；现在松抱闸算手动用车，要班组长按"继续"才走（产品负责人 2026-10-16）。挂起的其他原因（行驶中断电重启、按了急停按钮又松开等）照旧自动继续。
- **车队调度系统的行为**：
  - 有过观测（上一代的行为实验室和现场记录，样本少）：人手动用车时报过 `MODE_MANUAL`，车在动、没有订单；另有一次同样是人在用车，报的是 `MODE_AUTO`，车在动、没有订单，推测是在 Matrix 上让车走，没有记下用的是什么方式。松抱闸时 `mode` 仍是 `MODE_AUTO`，`breakSwitchState` 变成 `UNMOVABLE`；松着抱闸时新建的订单一直排队，抱闸合上后才开始执行。插手动充电器时 `batteryState` 报 `CHARGING`。
  - 产品负责人的说法，未实测，已记进 #11：`MODE_MANUAL` 就是人可以直接控制车前后左右行驶的模式；插着手动充电器时车动不了。
  - 待实测，已记进 #11：抱闸松着、`MODE_MANUAL`、插着手动充电器时，取消排队、暂停、挂起的订单能不能生效；切回自动模式、合上抱闸或拔下充电器以后，排队、暂停、挂起的单会不会自己开始执行。

## 考虑过的做法

- **认出手动用车时下三类急停按住车**：多一种急停原因，要和 ADR 0009 的解除规则对上；产品负责人不要急停，直接取消订单。
- **只停手、不取消已有的单**：松着抱闸时排着的单会在抱闸合上时当场执行。
- **不加规则，靠已有的挂起转故障（10 分钟）发现**：车上没单时什么都不会发生，SIMPLE 还会照常给它建单；抱闸一合上车可能自己走。
- **服务端看到这些迹象就自动停用这台车**：停用是人的决定（ADR 0011），车上有货时也不能停用。
- **迹象消失后自动恢复**：车会在人没想到的时候自己动起来，正是产品负责人说的"行为怪、人难以理解"。
- **只认手动模式一种迹象**：在 Matrix 上让车走、松抱闸推车时模式都不变，看不出来。
- **车在跑单时松抱闸照 ADR 0010 自动继续，只有车上没单时才算手动用车**：少按几次"继续"，但多一条例外，人看到的提示也不一样。
- **按车的位置突然变了、离开了站点来判断**：服务端在猜人的意图，和 ADR 0011"由人明确设定，比服务端去猜更清楚"相反；上面四种迹象都是车直接报的事实。
