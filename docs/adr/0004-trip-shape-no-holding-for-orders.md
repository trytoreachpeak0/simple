# 一趟车装多条任务，只在停站时追加，不原地持货等单

一趟车可以装同一派车区里几个取货站的多条任务，但形状固定为"先在一个派车区里取货，再去卸货"：车只在停在取货站上时接受追加，开始去卸货后不再加任务；装完、离站倒计时走完就走，不原地等新任务（已放宽，见 ADR 0035：固定站点可以把"全部装完"的倒计时配长，车在那里多等能追加的任务，不另加持货计时）。上一代生产里已经在用多任务的一趟，退回"一趟一条任务"对现场是倒退；而上一代为多接单做的持货等单、绕路上限和让站规则，是它最复杂的部分。首个厂区的机台和卸货站离得不远，直接去卸货的代价很小，还能尽快空出仓位，所以 SIMPLE 只保留多任务，不保留为多接单而等待的机制。

## 决定

- 派车时可以把同一派车区里几个取货站的任务一起分给一台车。
- 途中追加只在车停在取货站上时发生：同一派车区里冒出新任务、车上对应的仓位分组里空出的仓位数（不算已分配任务预留的）至少等于新任务的应装花篮数（同 ADR 0005），就加进这一趟，作为当前站或后面的一个停靠。车在行驶中不接追加；"车停在站上"是服务端自己记录的事实，不靠车载终端是否就绪来间接判断。
- 车开始去第一个卸货站后，这一趟不再加任务，不会出现卸到一半回去取货。
- 车在一个站上只收这个站的任务的货（已放宽，见 ADR 0036：这一站归这台车、没被抑制的需求，扫到就收，那一侧空仓够即可，不必事先分给这一趟）；扫到属于别的站的子批就拒收，要收得先把车开过去。
- 取货站之间、卸货站之间的先后都按车队调度系统给出的路径代价排，不另设规则。（已细化，见 ADR 0036：卸货站按整体路程最短的顺序走。）
- 不原地持货等单：取货站的任务装完、离站倒计时走完（见 ADR 0005），车就去下一个停靠。ADR 0003 里的结局"持货超时"因此不再出现。（已放宽，见 ADR 0035：固定站点上"全部装完"这一档可以配长。）
- 不设绕路上限（上一代的"最大晚到量"）：首个厂区没有加急产品，追加一条任务让已装的货晚到一点可以接受。

## 考虑过的做法

- **一趟只装一个取货站的任务**：最简单，但同一派车区里相邻两个站的货要跑两趟。
- **保留持货等单**（上一代：装完原地等新任务，直到装满、持货超时 5 分钟或给别的车让站）：为多接单增加了持货计时、让站和"按组判满"三套规则，而现场有人工兜底，多接的那一单不值这份复杂度。
- **按绕路上限控制追加**：适合有加急产品、要保证已装货物准时的现场；首个厂区不是这样，而且这个参数要逐区标定，上一代到最后也没标定完。

## 后果

ADR 0003 的结局清单里"持货超时"一项从此不会发生；该篇的决定不改，只在提到持货超时的地方注明见本篇。
