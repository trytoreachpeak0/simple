# 控制台三级角色按动作分界：班组长、工程师、管理员

控制台只设三个角色：班组长、工程师、管理员，高一级包含低一级的全部动作。和系统打交道的人有车旁的人（OP 等各种岗位）、班组长、工程师（客户方）和产品负责人；"人"不等于"角色"，车旁的人只用车载终端，不登录、没有账号（ADR 0005）。三级正好对上客户技术协议要求的"操作、技术、工程"三级权限：车旁的人在车载终端上什么参数都改不了。

班组长和工程师之间按"做的是哪个动作"分，不按"故障能不能恢复"分。产品负责人起初想让班组长只处理异常和可恢复故障、工程师处理不可恢复的硬件故障，但故障刚出现时往往分不清能不能恢复（例如"发了开锁命令，锁反馈没变"，可能是抽屉卡了一下，也可能是锁坏了，要等人到车旁看过才知道）；而且 ADR 0012 已定故障处置的动作对所有故障都一样，权限跟着故障类型走，等于又让分类决定了处置。按动作分，"硬件坏了要修"落到 SIMPLE 里就是那几个"宣布修好、重新投入使用"的动作，只给工程师，效果相同（产品负责人 2026-10-16）。

## 决定

- **分界一句话**：班组长能做一切"让车停下、把货取出来、让车接着做原来的事"的动作；工程师另外能做"宣布修好、重新投入使用"的动作；管理员另外能改参数配置（ADR 0017）、管账号（ADR 0016）。以后新加一个控制台动作，按这句话归级，不另立规矩。
- **动作表**（最低角色；免登录的车辆一览页上没有任何动作）：

  | 动作 | 出处 | 最低角色 |
  | --- | --- | --- |
  | 看本项目的车、任务、告警、事件记录、统计、当前生效的配置 | ADR 0015、0019 | 班组长 |
  | 解除二类急停（车载终端上不限人） | ADR 0009 | 班组长 |
  | 急停这台车 | ADR 0018 | 班组长 |
  | 手动判定故障 | ADR 0012 | 班组长 |
  | 继续 | ADR 0012 | 班组长 |
  | 取出货物交人工（含确认已取出；手动开过门的仓随之停用） | ADR 0012 | 班组长 |
  | 故障处置中单独打开出故障的仓门检修 | ADR 0012 | 班组长 |
  | 控制台放弃（车上还没有这条任务的货） | ADR 0003 | 班组长 |
  | 停用仓位（要确认有人亲眼看过门锁） | ADR 0012 | 班组长 |
  | 停用车（车上没货才能停） | ADR 0011 | 班组长 |
  | 停用的车上任意开门（车载终端上不限人） | ADR 0012 | 班组长 |
  | 重新启用仓位 | ADR 0012 | 工程师 |
  | 启用车（含车名对不上时确认一次） | ADR 0011 | 工程师 |
  | 确认车辆身份（新的或换了的车载电脑） | ADR 0007 | 工程师 |
  | 改参数配置 | ADR 0017 | 管理员 |
  | 管账号 | ADR 0016 | 管理员 |

- **停用车一律归班组长**：ADR 0011 原来区分"没货也没任务的车不限人停用，其余只有专业人员"，现在停用车只要车上没货，班组长就能做，不再区分。代价是班组长为手动挪车停用了一台好车，要还回去时得找工程师启用；启用不按班次开关（ADR 0011），不是天天做的事。
- **启用车归工程师**：启用多半发生在修好车之后，属于"重新投入使用"。
- **前几场 ADR 里的叫法**：ADR 0005、0008～0013 里的"专业人员"，一律指班组长及以上的角色；"现场人员"指车旁的人，即此刻在车旁的任何人，不是角色，不进术语表。
- **告警接收人**（改写 ADR 0013 的对应，四句规则不变）：
  - 不是故障的，先给车旁的人，显示在这台车的车载终端上，30 分钟没解决升级给本项目的班组长；
  - 是故障的，直接给本项目的班组长；修硬件、重新启用要工程师时，由班组长去找；
  - 服务端已经自己恢复的，只提示；
  - 急停发出后没确认的，车旁的人和班组长同时给。
  
  告警都显示在控制台上，本项目的班组长、工程师账号都看得到；"给谁"是"等谁去处理"，控制台上标出来。第一版仍不推送（ADR 0013）。
- **不设审批、不设两人规则**：每个动作由一个登录的账号按下就执行，服务端照各 ADR 先核对条件，每一次都记进事件记录（ADR 0019）。

## 考虑过的做法

- **按故障能不能恢复分班组长和工程师**：故障出现时多半分不清，权限没法判；又让故障分类决定了处置，与 ADR 0012 相反。
- **只设班组长、工程师两级，产品负责人也算工程师**：产品负责人要一个只有自己能改参数配置的最高权限。
- **沿用调研草稿的五级授权**（只读、安全方向、过程级、业务数据、物理动作，物理动作一次有效、15 分钟内）：级别多、人要学，"物理动作逐次授权"与 ADR 0011"车辆启用即动车授权"冲突。
- **三种告警接收人照旧，专业人员单独对应工程师**：处理故障的按钮都在班组长手里，告警给工程师，按按钮的却是班组长。
- **审批或两人规则**（控制台发起、车载终端确认）：每个动作多一步，现场等人；按下的账号和时间都在事件记录里，出了问题查得到。
