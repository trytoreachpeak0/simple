# 程序日志收进 factory01 上的 Seq，只经服务端读写，车载终端断联时先存后补送

值守 AI 要能发现车载终端和触控屏的 bug（产品负责人 2026-10-17）。光看服务端接口和事件记录不够：事件记录里有车旁的每次按键和扫码、服务端的每个决定，但没有程序自己出的错、卡死、闪退，也没有服务端和 MES 网关内部的异常；这些只在各程序自己的日志里（ADR 0019 说的"程序自己的调试日志"）。而日志散在 factory01 和每台车载电脑上；车载终端程序现在一行日志都不记，没被接住的错误也不留痕迹。

这是纯技术题，先调研几套方案、讲清现场后果，再由产品负责人挑（2026-10-17）。"凭直觉就会、方式少而统一"是给用系统的人定的，不拿来比技术方案（产品负责人 2026-10-17）；技术方案按成熟度（仓库 `CLAUDE.md`"优先用成熟的库"）、现场后果、安全和维护代价比。

## 决定

- **所有 SIMPLE 程序都写程序日志**：服务端、MES 网关、车载终端（包括没被接住的错误）用成熟的日志库写，同时在本机留一份限定大小的日志文件，送不出去时现场还能取。程序彻底崩溃、来不及自己写日志的情况，靠 Windows 自带的崩溃转储另外收。用哪个库、崩溃转储怎么收，由实现票定。
- **程序日志收进 Seq，Seq 装在 factory01 上，只让本机访问**（产品负责人 2026-10-17）。factory01 内存不够就腾出来（例如压缩其他占用、加内存条），不放到别的机器上。装 Seq、如需给它的数据目录加杀毒排除项，都在安装时另请产品负责人批准。
- **只有 SIMPLE 程序读写 Seq，Seq 自己的网页没有人用**：
  - 写入的是 factory01 本机上的服务端和 MES 网关；车载终端的程序日志顺着它和服务端之间现有的加密连接（ADR 0025）交给服务端，由服务端存进 Seq。车载电脑上不放 Seq 的钥匙，factory01 也不为 Seq 开端口；
  - 读只经服务端接口：值守账号（ADR 0033）和工程师及以上的账号都经服务端读。控制台上怎么显示由控制台的票定；
  - 观察系统仍然只有一个入口，服务端的接口（加事件记录）；Seq 是服务端背后的一层，换掉它，用的人感觉不到。
- **守住 Seq 免费版的两条限制**（产品负责人 2026-10-17）：
  - 只能一个人用：Seq 的网页没人用，读都经服务端。正式上生产前，书面问 Datalust（Seq 的厂家）这样用是否在免费版之内；如果不在，换成开源免费的 VictoriaLogs（Apache-2.0），服务端背后那一层换掉，其余不变；
  - 最多存 50 GB：在 Seq 里设只留 30 天，过期自动删。Seq 只能按天数删、不能按大小删，所以值守日报（ADR 0032）每天写一句 Seq 用了多少，超过 40 GB 值守 AI 开一份值守报告，提醒把天数调短。
- **车载终端断联时，程序日志先存在车上，连回后补送给服务端**：车上存的有大小上限，满了丢最旧的。这改了 ADR 0024 的"日志只给人排查，程序从不读回"：补送是唯一的读回。车载终端仍然不存任务、仓位这些业务状态，断电重启也不留要对账的东西。
- 程序日志不是事件记录（ADR 0019）：统计不从它算，"谁按了什么"仍然只查事件记录。

## 后果

- 车载终端和服务端之间多了"送日志、收日志"一件事，车上的 Wi-Fi 多走一些流量。
- factory01 多一个要备份、要看着的 Windows 服务；Seq 最少要 3.5 GB 内存，factory01 上还跑着上一代系统，装之前要实测。
- 车载终端彻底起不来、一直连不上时，它的日志送不上来；这种情况本来就会被当成车载终端故障告警（ADR 0008），要人到车旁去看，车上的日志文件还在。

## 考虑过的做法

调研于 2026-10-17 读了各产品的官方文档、发布页和 NuGet 上的包。

- **日志都交给服务端，我们自己写收集、存储、查询**：现场不用装新东西；但断联缓存、存储、按天删、搜索都是通用基础设施，仓库规则反对手写；生产库如果是 SQL Server Express，一个库最大 10 GB，日志和业务数据挤在一起可能撑满，连派车都受影响。
- **工程师和 AI 远程登录 factory01 和车载电脑读日志文件**：不用改程序，但跑 AI 的机器上要放能登录生产机器的钥匙，"只看"就成了空话。
- **Seq 装在 simple01 上**：不动 factory01、内存宽裕；但生产日志放在一台走 Wi-Fi、防火墙全关、还在跑 CI 的笔记本上。产品负责人定一定装 factory01。
- **车载终端直接把日志送进 Seq**（Seq 的客户端自带断网缓存）：每台车载电脑要放一把往 Seq 写的钥匙，factory01 要为 Seq 开端口；Seq 的厂家自己也不建议普通程序用那个断网缓存。
- **买 Seq 团队版（约每年 1,090 美元），让工程师各自登录 Seq 的网页**：查日志的界面更强；产品负责人要在免费版限制里用。
- **其他开源免费的**：VictoriaLogs（Apache-2.0，单个程序，占用小，但官方称 Windows 版"实验性"）留作退路；OpenObserve（开源版在 Windows 上不是主推的构建，只读角色要企业版）；Grafana Loki 加 Grafana（两个服务、自身不带鉴权、Windows 只有手动安装方式且有未修的启动问题）；OpenSearch、Elasticsearch（要 Java、吃内存，factory01 扛不住）；Graylog、SigNoz、Quickwit（只能跑在 Linux 上，现场没有 Linux 机器）。
