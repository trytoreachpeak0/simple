# 控制台用共用的本地账号，登录不定时失效，另有免登录的车辆一览页

控制台账号按项目、按角色共用：每个项目一个班组长账号、一个工程师账号，整个 SIMPLE 一个管理员账号，在产品负责人手里，大概率不会交出去（产品负责人 2026-10-16）。管账号只有管理员能做（ADR 0014），每人一个账号的话，每个车间换一个班组长、来一个新工程师，都要产品负责人去开、去删，几个项目下来就成了专门管账号的人。ADR 0005 不让车载终端输工号，理由是工号容易被绕过、记了也不一定准；共用账号是同样的思路，不假装能精确记到人。

## 决定

- **账号**：每个项目一个班组长账号、一个工程师账号，由这个项目的同一批人共用；一个管理员账号。账号由管理员在控制台上建、改密码、删。有人离开就由管理员改这个共用账号的密码。事件记录写到"哪个项目的哪个角色账号"为止（ADR 0019），要追溯到具体的人，靠现场的排班。
- **登录**：SIMPLE 自己的本地账号（账号名加密码），不接厂内 AD：AD 是一人一个账号，和共用账号对不上。看控制台一律要登录。
- **不做定时回落**：登录后一直有效，直到人自己退出（产品负责人 2026-10-16）。客户技术协议要求"可定时自动回落到最低权限"，这一条有意不满足：仓库里的协议是未签字的版本；账号共用，知道密码的人本来就不少，回落只挡得住不知道密码的人；而班组长开着控制台主要是为了看告警，第一版又不推送（ADR 0013），自动退出会让他看不到升级来的告警。代价是没人看着的、登录着的控制台，走过来的人能用它按按钮，包括"继续"。
- **车辆一览页**：每个项目一个不用登录就能打开的只读页面，地址里带项目名，给派工待送区（staging）这类要知道车在哪、却不处理异常的员工看（产品负责人 2026-10-16）。只显示本项目每台车三样东西：在哪（停在哪个站点，或正在去哪个站点）、在做什么（车辆用途：跑一趟、充电、空闲返回，或空闲）、现在能不能接任务及原因（ADR 0011）。不显示告警、任务明细、事件记录，没有任何按钮。（已定，见 ADR 0029：用和控制台同一张地图只读显示，下方附一张小表，内容不变。）
- **控制台是网页**，厂区网内用浏览器打开；前端框架由实现控制台的票定。（已定，见 ADR 0031：React 加 TypeScript 的单页应用，只调服务端接口；页面与操作方式见 ADR 0029、0030。）
- **AI 经 MCP 用管理员账号，MCP 只能看和改参数配置**：产品负责人让自己的 AI 会话经 MCP 改配置，是替他干活，用他的账号；事件记录同时写账号和入口（ADR 0019），分得清哪些是经 MCP 做的。MCP 入口只能查看，和修改参数配置（事件记录保存天数除外）；别的动作一概不经 MCP，让车动的（启用车、继续、解除急停、急停这台车、取出货物交人工开门等）和管账号、改密码的，都只在控制台上做（产品负责人 2026-10-16）。任务类型开关 MCP 也能打开：动车授权在"启用车"上（ADR 0011），而 MCP 启用不了车。AI 自己在生产上值守时用什么账号、能做什么，另定。
- **接受的代价**（产品负责人 2026-10-16）：
  - 工程师账号的共用密码就是本项目的动车授权（启用车归工程师，ADR 0014）：有人离开后、管理员改密码之前，他仍能登录启用车。
  - 管理员凭据会落在 AI 会话的 MCP 配置里。MCP 边界挡住了让车动的动作和管账号，但经 MCP 仍能改全部参数配置；凭据一旦泄漏，拿到的人不经 MCP、直接登录控制台，就什么都能做，包括启用车、继续、解除急停、改密码、缩短事件记录保存天数。

## 考虑过的做法

- **每人一个账号**：能追溯到人，但只有管理员能管账号，产品负责人一个人管不过来。以后客户要求追溯到人，再换成每人一个账号，角色和动作表（ADR 0014）不用改。
- **最高权限也做成角色、可以有多个账号**：最高权限应当收在一个人身上。
- **接厂内 AD**：要一人一个账号，还要和客户 IT 打交道。
- **空闲一段时间自动退出，或回落成只读、按按钮前重输密码**：前者让班组长看不到告警；后者满足协议，但产品负责人认为对共用账号意义不大，不做。
- **不做免登录页面**：派工待送区的员工要么拿班组长的密码，要么什么都看不到。
- **免登录页面显示全部项目、或显示告警和任务明细**：与"每个项目只看本项目"对不上；谁都能打开的页面，内容越少越不用担心被误解。
- **给 AI 单独开一个和管理员同级的账号**：最高权限就变成两个账号。
- **MCP 对任务类型开关和不服务的区域号只能往停的方向改**：更保守，但边界变成"有些配置项只能单向改"，多一条规矩；动车授权已经落在 MCP 碰不到的"启用车"上，再给配置分方向是把同一道闸设了两遍。
- **桌面程序**：每台用的电脑都要安装、逐台升级。
