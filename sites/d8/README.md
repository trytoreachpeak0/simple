# D8

D8 厂区的起始业务配置：区域、地图、任务类型、车辆清单这类业务设置，按现场的真实值写。首次安装时用服务端命令 `import-site` 导进服务端，之后以服务端里的配置为准，在控制台上修改（见 `docs/adr/0017-site-config-lives-in-server.md`）；测试和场景也用这里的配置。产品代码不按厂区分支，每个厂区的业务差异都放在各自的 `sites/<厂区>/` 下。格式见 `sites/README.md`。

这里不放 SIMPLE 要连接的端点，也不放凭据。调度平台、车辆、MES 的真实地址从仓库外提供，每次运行由人明确选用；口令、密码、密钥、令牌，以及带这些内容的连接串，永远不进仓库。

## 待定

v2 线里没有、或者和 SIMPLE 的规则对不上的值，先按下面写了，等产品负责人定：

1. **项目**：编号和中文名。v2 线只有一批班组长和工程师，这里先写一个项目 `D8`。
2. **装片区的中文名**：v2 线只有编号 `DIE_ATTACH`，"装片区"是照任务类型的中文名拟的。
3. **每台车的等待点**：v2 线的 214、215、216 三个等待点不分车，谁空去谁，生产上也没开"没活回等待点"。SIMPLE 每台车要有自己的等待点、两台车不共用（ADR 0021），这里按顺序先给 agv01 214、agv02 215、agv03 216。v2 里 agv02 跑完一趟留在待送区 217，但 217 是固定站点，不能再当等待点。
4. **焊线送全检（`WIRE_TO_FULL_INSPECTION`）**：26 号图上还没有全检站，所以没配固定站点；照 v2 的 s3 定义先给了 agv01，v2 生产上还没开这一类。导入后所有任务类型本来就关着，开它之前要先补固定站点。
5. **`T8-8`**：v2 线 10-17 导入时去掉了它（MES 里还挂着一条 09-02 的陈旧需求），这里照此设为不服务；以后要不要送待定。
6. **T 开头区域号的开门侧**：只找到 v2 线生产用的输入文件，没找到是谁、什么时候定的。
7. **电量线**：v2 线的"强制充电线"40%（三台车约 25% 会突然掉电，10-18 从 30% 调到 40%）对应 SIMPLE 的去充电线，"完成充电"80% 对应充满线；紧急充电线、可接活线 v2 没有对应值，用默认的 20%、60%。这样对应是否合适待定。
8. **IO 模块型号**：v2 仓库里没写，"C2000"是按车上装的 `C2000Service.exe` 推测的；它不影响这份配置（点位对应表只写 DI、DO 的编号）。
